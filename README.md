# Document Schematic

Web app สำหรับรวมเอกสารจาก OneDrive ไว้ที่เดียว พร้อมระบบค้นหาและการติดตาม Revision ของเอกสาร

- ดึงเอกสารจาก URL ของ OneDrive / SharePoint ผ่าน Microsoft Graph API
- ค้นหาจากชื่อ เลขที่เอกสาร หมวดหมู่ และเนื้อหาในไฟล์ (รองรับภาษาไทย)
- ตรวจจับการแก้ไขอัตโนมัติ แสดงป้าย **Revised** และประวัติ Revision

ดูรายละเอียดการออกแบบได้ที่ [docs/SYSTEM_DESIGN.md](docs/SYSTEM_DESIGN.md)
